# Pollo Asado API

API REST para la gestión de una pollería especializada en la preparación y venta de pollo asado.

## Descripción

El proyecto consiste en el desarrollo de una API REST para administrar los principales recursos de una pollería de pollo asado.

La API permitirá gestionar:

- Productos
- Clientes
- Pedidos

El proyecto es desarrollado para la asignatura Ingeniería Web II de la Universidad Manuela Beltrán.

## Objetivos

- Implementar una API REST siguiendo los principios de la arquitectura REST.
- Diseñar y documentar la API utilizando OpenAPI 3.0.
- Implementar operaciones CRUD para los recursos principales.
- Utilizar Node.js y Express para el desarrollo del backend.
- Utilizar GitHub para el control y gestión del código fuente.
- Utilizar GitHub Copilot como asistente de codificación, realizando una revisión crítica del código generado.

## Tecnologías

- Node.js
- Express
- Git
- GitHub
- GitHub Copilot
- OpenAPI 3.0
- Swagger Editor
